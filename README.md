# ZenMoney Token Page

Страница получает API-токен ZenMoney, хранит его только в браузере и позволяет переключаться между несколькими аккаунтами.

Рабочая версия доступна на [token.zentable.ru](https://token.zentable.ru/). Она использует серверный OAuth-брокер: приватный `client_secret` остаётся на сервере.

## Локальный запуск

Локальный режим не обращается к `token.zentable.ru`. Он использует публичную development-регистрацию OAuth из [Zerro](https://github.com/ardov/zerro/blob/master/.env.development) с фиксированным адресом возврата `http://localhost:3000`.

```sh
mise trust
mise exec -- bun start
```

Откройте [http://localhost:3000](http://localhost:3000). После входа токен останется в `localStorage` этого origin. Локальный сервер слушает только `127.0.0.1`.

## Разработка

Зависимостей и шага сборки нет. Статика находится в `public`, локальный сервер — в `src/server.ts`.

```sh
mise exec -- bun test
```

Production-брокер подключает этот репозиторий как зафиксированный git submodule. Обновление `main` здесь само по себе не меняет задеплоенную страницу: владелец брокера отдельно обновляет commit submodule, проверяет и выпускает общий образ.

## Безопасность

Любой JavaScript на origin страницы может прочитать сохранённые токены. Поэтому страница не подключает сторонний код и обслуживается со строгой Content Security Policy. Удаление токена из браузера не отзывает доступ в ZenMoney.
