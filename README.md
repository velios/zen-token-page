# Токены ZenMoney

Получите API-токен своего аккаунта ZenMoney и скопируйте его для приложения или бота.

Можно воспользоваться [готовым сервисом](https://token.zentable.ru/) или запустить страницу на своём компьютере. При локальном запуске браузер обращается напрямую к ZenMoney.

## Запуск

Установите [Bun](https://bun.sh/), затем выполните:

```sh
git clone https://github.com/velios/zen-token-page.git
cd zen-token-page
bun start
```

Откройте [http://localhost:3000](http://localhost:3000), нажмите «Войти через ZenMoney» и после входа нажмите «Скопировать».

Используйте именно этот адрес. Локальный вход настроен на публичные [OAuth-креды Zerro](https://github.com/ardov/zerro/blob/master/.env.development) и не работает на другом домене или порту.

Токены сохраняются только в вашем браузере. Можно добавить несколько аккаунтов и переключаться между ними. «Удалить из браузера» удаляет сохранённый токен, но не отзывает его в ZenMoney.

Не передавайте токен другим людям: он даёт доступ к данным аккаунта.
